# 위성 단일축 자세제어 시스템 (Satellite 1-Axis Attitude Control)

## 프로젝트 개요

본 프로젝트는 MATLAB을 활용하여 **PD 제어기 기반 위성 단일축 자세제어 시스템**을 설계하고, 시스템의 안정성과 제어 성능을 분석하는 것을 목표로 합니다.

위성의 회전 운동과 리액션 휠의 동특성을 전달함수로 모델링하고, 주파수 영역 및 시간 영역에서 제어 시스템의 응답을 분석합니다.

## 시스템 구성

시스템은 다음과 같은 요소로 구성됩니다.

- **위성 동역학 모델:** 관성모멘트를 기반으로 위성의 회전 운동 모델링
- **PD 제어기:** 비례 및 미분 제어를 통한 자세 오차 보정
- **리액션 휠 모델:** 1차 전달함수를 이용한 구동기 응답 특성 반영
- **폐루프 제어 시스템:** 목표 자세각에 대한 위성의 추종 성능 분석

### 주요 시스템 파라미터

| 항목 | 설정값 |
|---|---|
| 위성 관성모멘트 | 0.08 kg·m² |
| 비례 이득 (Kp) | 0.005 |
| 미분 이득 (Kd) | 0.028 |
| 미분 필터 시정수 | 0.02 s |
| 리액션 휠 시정수 (가정값) | 0.05 s |
| 목표 자세각 | 10° |
| 리액션 휠 운용 토크 한계 | ±1 mNm |
| 시뮬레이션 시간 | 30 s |

## 주요 구현 기능

**1. 주파수 영역 안정성 분석**

- 개루프 전달함수 기반 Bode Plot 생성
- Gain Margin(GM) 및 Phase Margin(PM) 계산
- 이득 및 위상 교차 주파수 분석

**2. 폐루프 자세제어 시뮬레이션**

- 10° 목표 자세각에 대한 위성의 응답 분석
- 상승시간(Rise Time), 정착시간(Settling Time), 오버슈트(Overshoot) 계산
- 시간에 따른 자세각 변화 시각화

**3. 리액션 휠 토크 분석**

- 자세제어에 필요한 토크 명령 계산
- 최대 토크 요구량 분석
- ±1 mNm 운용 한계와 토크 명령 비교
